# 建模与导出说明

## 为什么不用 Blender

沙箱内没有 Blender，模型由 Node 脚本 **程序化生成**：所有曲面都由解析式定义（超椭圆平面轮廓、
后盖高度样条、截面扫掠），再写入自定义的 glTF 2.0 二进制。这样做的额外好处是尺寸完全可复现：
`npm run model` 每次生成的 GLB 顶点数据一致，便于回归比较。

## 机身

机身不是基础几何体拼装，而是四条连续曲面：

1. **平面轮廓**：`|x/23.285|^2.79 + |y/11.27|^2.79 = 1`。
   指数 2.79 由拆解实拍 T06 的轮廓点最小二乘拟合（RMSE 2.0 px ≈ 0.35 mm），见 `references/measure.py`。
2. **前玻璃**：中心平坦，边缘做 2.5D 卷边（圆角半径按 1.15 mm 落差），黑边区与覆盖玻璃分区建模。
3. **中框**：沿轮廓向内的偏移量 d 与高度 z 组成的 7 点剖面（`FRAME_P`）扫掠成环。
   最外沿 z=4.16 处形成"钻石切边"，侧面哑光，底缘收进后盖。
4. **后盖**：以归一化半径 ρ 为参数的高度样条（`BACK_Z`，9 个控制点），从框缘 z=+1.30 过渡到
   中心 z=−5.475，接近中心处趋于平坦。

传感器模组是从后盖表面"长出"的独立凸台（0.62 mm 高，带 3 级倒角），三个窗口贴在台面上；
两枚充电触点用旋转体（lathe）生成并嵌入后盖；快拆按钮是贴合后盖曲面的一片椭圆凸包。

## 表带

- **路径**：180 mm 腕围对应的圆弧（R=28.6 mm，圆心 z=−17 mm），从机身端部（41°）绕到环底（−90°）。
- **截面**：起始段直接包裹机身端部（截面尺寸由机身同一套超椭圆/后盖样条算出，+1.5 mm 间隙），
  在 22% 行程内过渡到 20 × 2 mm 的扁平表带。两者共用一套数学描述，因此不会出现"零间距硬拼"。
- **孔洞**：TPU 表带为真穿孔——在上下表面网格上按孔位掩码剔除四边形，再把孔边界上下缝合出内壁，
  不是贴图伪造。
- **金属链**：逐节生成超椭圆截面的链节，每节刚性绑定到一根骨骼，弯曲时按节转动。
- **骨骼**：每条半带 9 根骨骼，骨骼世界矩阵取路径采样点的切线/法线/副法线构成的正交基，
  `inverseBindMatrices` 为其逆。前 16% 行程 100% 绑定到根骨骼，保证 lug 相对机身刚性。

## 导出检查

`npm run check:gltf`（gltf-validator）：

```
triangles : 102692
vertices  : 52562
materials : 14   skins: 10
issues    : 0 errors, 0 warnings, 10 infos
```

10 条 info 是 `UNUSED_OBJECT`（无贴图材质仍带 TEXCOORD_0）与 `IMAGE_NPOT_DIMENSIONS`
（表盘贴图 424×1040），不影响加载。

`npm run check:intersect`：5 种表带 × 2 半 × 4 个弯曲角度，用空间哈希 + SAT 三角相交检测，
结果 `no self-intersection in any strap at any allowed bend`。

逐项检查清单：

| 项 | 结果 |
|---|---|
| 面法线朝向 | 每个部件导出前用散度定理算有符号体积，负值则翻转索引（`Mesh.orient()`），平面贴片用 `faceUp()` |
| UV 展开 | 机身平面网格用平面投影；中框用轮廓弧长×剖面高度；表带用毫米尺度（13 mm 一循环）；屏幕/后盖用 0..1 归一化投影 |
| 材质槽分配 | 每个部件一个 primitive、一个材质，共 14 个材质、19 个 draw call |
| 切线 | 仅对有法线贴图的材质导出 TANGENT（VEC4，含手性） |
| 蒙皮 | 每顶点 4 组 JOINTS_0/WEIGHTS_0，权重和恒为 1，无零权重关节 |

## 已知简化

- 表带扣件（蝶形扣、磁吸扣）未建模为可动机构。
- 表带孔壁为直壁，无倒角。
- 传感器模组内部结构（LED/光电二极管本体）不可见，只建外窗。
- AO 未烘焙成贴图：程序化管线没有烘焙器，间接遮蔽由 HDRI + 实时阴影近似。
