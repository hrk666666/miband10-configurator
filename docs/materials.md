# 材质标定记录

所有参数都是「引擎反照率 / 金属度 / 粗糙度」，不是从参考图上直接吸取的像素值。
原因：金属的观测亮度由环境反射决定，直接把高光像素当 baseColor 会把金属做成塑料。
因此流程是「按参考图给初值 → 渲染 → 用同一机位与参考图比较 → 修正」，见 `CHANGELOG.md`。

关键判断：

- **屏幕用无光照材质（MeshBasicMaterial）**。第一版用 Standard 材质时，即便 baseColor 为纯黑，
  F0≈0.04 的电介质高光仍把黑色抬到 sRGB≈29（见 CHANGELOG 第 1 轮问题 P3）。
  OLED 是自发光器件，正确做法是不参与光照，反射交给上方的玻璃层。
- **覆盖玻璃用 3.2% 不透明度的透明层**，只贡献镜面反射。KHR_materials_transmission 版本在
  headless SwiftShader 下慢 3 倍且视觉差异很小，故运行时关闭，GLB 中仍保留该扩展。
- 玻璃黑边与覆盖玻璃共面，黑边层略微下沉 0.012 mm 以避免 z-fighting。

## 环境光

自建棚拍 HDRI（`model/hdri.py` → `public/hdri/studio.hdr`，1024×512，Radiance RGBE + RLE）：

| 光源 | 方位（u, v） | 强度 | 作用 |
|---|---|---|---|
| 主柔光箱 | 0.06–0.31, 0.09–0.31 | 6.5 | 玻璃与中框的主高光 |
| 右侧条形灯 | 0.65–0.74, 0.15–0.63 | 3.2 | 金属边缘的竖条反光 |
| 正面补光 | 0.40–0.60, 0.38–0.56 | 0.30 | 避免正面全黑 |
| 背侧轮廓光 | 0.85–0.93, 0.28–0.42 | 1.6 | 勾边 |
| 基底 | — | 0.010–0.013 | 暗房基调 |

基底亮度是关键：第一版基底 0.035 + 地平线辉光 0.16，导致平面玻璃整面反射成灰色（P2）。

## 与参考图的偏差（诚实记录）

| 项目 | 偏差 | 原因 |
|---|---|---|
| 黑边宽度 | 模型 2.42 mm（像素测量），官方口径 2.0 mm | 官方 2.0 mm 与 1.72″/212×520/22.54 mm 三个数字不能同时成立（见 manifest D8–D10），取几何自洽值 |
| 陶瓷版光泽 | 略低于官方渲染 | 无实拍样本，按渲染图估 |
| 表带扣件 | 未建模蝶形扣/磁吸扣机械结构 | 参考图不足以支撑内部结构，避免臆造 |
| 表带孔壁 | 直壁，无倒角 | 分辨率与面数取舍 |
